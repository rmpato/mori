Every day already exists.

No “new entry” step — most days are simply empty. Come back after a few hours and mori stamps the time for you.

A page is just Markdown.

One small file per day, in a folder you own. No database, no index, nothing that can take the whole journal down with it.

~/.local/share/mori/journal/
2026/08/2026-08-17.md

Nothing is counted.

No streaks, no scores, no goals, and no “you haven't written lately”. Come back after three weeks and it just says welcome back.

If you have both, press tab and mori shows what you got done that day while you decide what to say about it. It will never turn your task list into prose and call it your writing — that rule is the reason the two tools are separate. Read-only, optional, and silent when tuki isn't there.

Install

However you'd normally reach for it.

$ curl -fsSL https://raw.githubusercontent.com/rmpato/mori/main/install.sh | sh

Checks the download against the release's own sha256, installs to ~/.local/bin, and adds it to your PATH if it isn't there.

$ go install github.com/rmpato/mori@latest

Lands in ~/go/bin, which isn't on your PATH by default.

$ git clone https://github.com/rmpato/mori
$ cd mori && make install

Go 1.26 or newer.

Archives for macOS, Linux and Windows are on the releases page. Later, mori update keeps it current — it asks first, and it is the only command that touches the network.

🌱

What it doesn't do

  • accounts or sync
  • cloud, ever
  • streaks
  • notifications
  • mood charts
  • telemetry

Your journal is stored at 0600 in a directory only you can read. Nothing is sent anywhere — and neither is anything on this page, which loads no fonts, no analytics, and no third-party anything.
