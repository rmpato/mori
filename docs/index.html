Using it

Type mori and today's page is open. That's the whole idea.

Write

There is no "new entry" step — every day already exists, and most are simply empty. ↵ starts writing and esc stops. Your words are saved when you pause, when you stop, and when you leave.

Come back to a day hours later and mori stamps the time for you.

Look back

← → move through days, c opens the calendar, / searches as you type, and # lists the tags you've used.

? shows every key there is.

It behaves in a pipe

When output isn't a terminal, mori hands you the file rather than a drawing of it:

$ mori show yesterday        # or: fri, -3d, 2026-08-17
$ mori search photography   # newest day first
$ mori looking-back august  # a month, read back
$ $EDITOR "$(mori path today)"

Every printing command takes --plain and --json.

Your journal

One plain Markdown file per day, in a folder you own.

~/.local/share/mori/journal/2026/08/2026-08-17.md

Written atomically, at 0600, in a directory only you can read. Tags are the hashtags in your prose; ## HH:MM marks a second sitting. No database and no index — if mori disappeared tomorrow, your journal would still be there.

mori will never turn your task list into prose and call it your writing — that rule is the reason the two are separate tools. The bridge is optional, read-only, and silent when tuki isn't installed.

Install

However you'd normally reach for it.

The one-liner at the top of this page is the usual way: it checks the download against the release's own sha256, installs to ~/.local/bin, and puts that on your PATH. If you'd rather not pipe a script:

$ go install github.com/rmpato/mori@latest

Lands in ~/go/bin, which isn't on your PATH by default.

$ git clone https://github.com/rmpato/mori
$ cd mori && make install

Go 1.26 or newer.

Archives for macOS, Linux and Windows are on the releases page.

Afterwards mori update keeps it current. It asks first, and it is the only command that touches the network.

What mori doesn't do

Journalling, not measuring.

  • accounts or sync
  • cloud, ever
  • streaks
  • notifications
  • mood charts
  • telemetry

Nothing on this page is sent anywhere either: no fonts, no analytics, no third-party anything. It seemed like the least a page about a private journal could do.
